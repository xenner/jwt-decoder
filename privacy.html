Privacy Policy — JWT Decoder

Last updated: November 16, 2026

JWT Decoder does not collect, sell, share, or transmit personal data.

Data processed

The extension works only with the text you explicitly select or paste:

  • The JWT you select on a page or paste into the toolbar popup.
  • The decoded header, payload and signature, shown only in the browser tab where you requested them.

All decoding happens locally in your browser. The selected or pasted token is website content; it is handled only in memory to display the result. The token is never sent to the developer or to any third party, never written to disk, and never stored in chrome.storage or a log. Closing the panel or the popup discards it.

Permissions

  • contextMenus: adds the JWT Decode item to the right-click menu when text is selected.
  • activeTab: grants temporary access to the current tab only after you choose that menu item, so the extension can show the decoded panel there. There is no permanent access to websites.
  • scripting: injects the extension's own packaged files into the active tab after that click.

The extension requests no host_permissions, has no content scripts on all sites, and makes no network requests. Its only fetch call loads the extension's own local stylesheet.

Third parties

No analytics, telemetry, advertising, accounts, external servers or third-party services are used. No data is sold or shared.

Signature verification

JWT Decoder does not verify signatures. It only reads the contents of the token. A token can be decoded successfully and still be invalid, expired or forged. Encrypted tokens (JWE) cannot be decrypted without the key.

Changes

If this policy changes, the updated version will be published on this page with a new date.
